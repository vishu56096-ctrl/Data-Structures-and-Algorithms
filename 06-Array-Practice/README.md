# Array Practice

Programs in this folder practice the most important introductory array operations:

- `ArraySumAverage.java` — calculate the sum and average of elements
- `EvenOddCount.java` — count even and odd values
- `FrequencyElement.java` — find the frequency of an element
- `LargestSmallest.java` — find the largest and smallest values
- `SecondLargest.java` — find the second-largest value
- `ReverseArray.java` — reverse an array
